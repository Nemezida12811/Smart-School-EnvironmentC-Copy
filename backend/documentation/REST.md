# API Documentation

Detailed information about the REST API provided by the backend.

## Base URL
Default: `https://iotproj-backend-nad.onrender.com`

---

## Authentication Routes

### POST `/api/auth/register`
Register a new user.
- **Request Body**:
  ```json
  {
    "username": "string",
    "email": "string",
    "password": "string"
  }
  ```
- **Response (201)**:
  ```json
  {
    "success": true,
    "data": {
      "message": "User registered successfully",
      "token": "jwt-token-string",
      "user": {
        "id": "507f1f77bcf86cd799439011",
        "username": "testuser",
        "email": "test@example.com",
        "role": "user"
      }
    }
  }
  ```

### POST `/api/auth/login`
User login.
- **Request Body**:
  ```json
  {
    "email": "string",
    "password": "string"
  }
  ```
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": {
      "message": "Login successful",
      "token": "jwt-token-string",
      "user": {
        "id": "507f1f77bcf86cd799439011",
        "username": "testuser",
        "email": "test@example.com",
        "role": "user",
        "createdAt": "2025-12-16T15:00:00.000Z"
      }
    }
  }
  ```

### POST `/api/auth/logout`
User logout.
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "Logout successful" }
  }
  ```

### GET `/api/auth/me`
Get current user info (requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": {
      "id": "507f1f77bcf86cd799439011",
      "username": "testuser",
      "email": "test@example.com",
      "role": "user",
      "ownedLocationIds": ["location-id-1", "location-id-2"],
      "accessibleLocationIds": ["location-id-3"],
      "createdAt": "2025-12-16T15:00:00.000Z"
    }
  }
  ```
- **Error Response (401)**:
  ```json
  {
    "success": false,
    "message": "No token provided"
  }
  ```
  or
  ```json
  {
    "success": false,
    "message": "Invalid or expired token"
  }
  ```
- **Error Response (404)**:
  ```json
  {
    "success": false,
    "error": {
      "message": "User not found",
      "statusCode": 404
    }
  }
  ```

## Comfort Routes

### GET `/api/comfort/:audienceId`
Get comfort percentage for a specific audience.
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": {
      "audienceId": "pico-001",
      "comfortPercentage": 73,
      "timestamp": "ISO-DATE"
    }
  }
  ```

### GET `/api/comfort/:audienceId/recommendations`
Get improvement recommendations generated by AI.
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": {
      "audienceId": "pico-001",
      "recommendations": [
        {
          "priority": "medium",
          "type": "light",
          "message": "Dim the lights or use curtains to diffuse bright light.",
          "reason": "Current light level (1120 lx) exceeds the upper norm (1000 lx), which may cause eye fatigue."
        },
        {
          "priority": "low",
          "type": "sound",
          "message": "Try to reduce background noise levels...",
          "reason": "Noise level is at the maximum limit for a comfortable environment (50 dB)..."
        }
      ],
      "generatedAt": "2026-01-20T19:03:37.101Z"
    }
  }
  ```

### GET `/api/comfort/:deviceId/sensors`
Get latest sensor measurements for a specific device.
- **Response (200)**:
  ```json
    {
        "success": true,
        "data": {
            "deviceId": "pico-001",
            "name": "Kitchen Sensor",
            "hidden": false,
            "latestReading": {
                "temperature": 23.4,
                "humidity": 41,
                "gas": 400,
                "light": 1120,
                "sound": 50,
                "units": {
                    "temperature": "standard",
                    "humidity": "%",
                    "gas": "ppm",
                    "light": "lx",
                    "sound": "dB"
                }
            },
            "timestamp": "2026-01-20T19:34:26.000Z"
        }
    }
  ```

### PATCH `/api/locations/:id/devices/:deviceId/settings`
Update device settings (Admin only, requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Request Body**:
  ```json
  {
    "name": "Living Room Sensor",
    "units": "standard",
    "ntpHost": "pool.ntp.org",
    "brokerAddress": "broker.emqx.io",
    "wifiSsid": "MyWiFi",
    "wifiPassword": "Password123",
    "interval": 10000
  }
  ```
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": {
      "message": "Device settings updated and published",
      "topic": "iot/backend/device-id/settings",
      "settings": { ... }
    }
  }
  ```

## Location Routes

> [!IMPORTANT]
> All location routes require JWT authentication. Include the Authorization header with Bearer token in all requests.

### GET `/api/locations`
Get all locations for the authenticated user (requires authentication).
The response separates locations into those created by the user and those they have joined.
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": {
      "created": [
        {
          "id": "location-id-1",
          "name": "My Home",
          "adminId": "user-id-from-token",
          "userIds": ["user-id-from-token"],
          "deviceIds": [],
          "createdAt": "ISO-DATE"
        }
      ],
      "joined": [
        {
          "id": "location-id-2",
          "name": "Work",
          "adminId": "other-user-id",
          "userIds": ["other-user-id", "user-id-from-token"],
          "deviceIds": [],
          "createdAt": "ISO-DATE"
        }
      ]
    }
  }
  ```

### POST `/api/locations`
Create a new location (requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Request Body**:
  ```json
  {
    "name": "My Home"
  }
  ```
  > **Note**: `adminId` is automatically extracted from the JWT token
- **Response (201)**:
  ```json
  {
    "success": true,
    "data": {
      "id": "location-id-string",
      "name": "My Home",
      "adminId": "user-id-from-token"
    }
  }
  ```

### GET `/api/locations/:id`
Get location details (requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
  > **Note**: User must be a member of the location to access it
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": {
      "id": "location-id-string",
      "name": "My Home",
      "adminId": "user-id-string",
      "userIds": ["user-id-1", "user-id-2"],
      "deviceIds": ["device-1"],
      "createdAt": "ISO-DATE"
    }
  }
  ```
- **Error Responses**:
  - **403**: User is not a member of the location
  - **404**: Location not found

### PATCH `/api/locations/:id`
Update location name (Admin only, requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Request Body**:
  ```json
  {
    "name": "New Location Name"
  }
  ```
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "Location updated", "name": "New Location Name" }
  }
  ```
- **Error Responses**:
  - **400**: Name is required
  - **403**: Only admin can update location
  - **404**: Location not found

### DELETE `/api/locations/:id`
Delete a location (Admin only, requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
  > **Note**: Only the admin (creator) can delete the location
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "Location deleted" }
  }
  ```
- **Error Responses**:
  - **403**: Only admin can delete location
  - **404**: Location not found

### POST `/api/locations/:id/users`
Add a user to a location.
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Request Body**:
  ```json
  {
    "targetUserId": "user-id-to-add"
  }
  ```
  > **Note**: Admin ID is extracted from JWT token
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "User added to location" }
  }
  ```
- **Error Responses**:
  - **403**: Only admin can add users
  - **404**: Location or target user not found

### DELETE `/api/locations/:id/users/:userId`
Remove a user from a location (Admin only, requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
  > **Note**: Admin ID is extracted from JWT token. Cannot remove the admin from the location.
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "User removed from location" }
  }
  ```
- **Error Responses**:
  - **400**: Cannot remove admin from location
  - **403**: Only admin can remove users
  - **404**: Location not found

### POST `/api/locations/:id/devices`
Add a device to a location (Admin only, requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Request Body**:
  ```json
  {
    "deviceId": "device-id-string",
    "name": "Kitchen Sensor"
  }
  ```
  > **Note**: Admin ID is extracted from JWT token. `name` is optional.
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "Device added to location" }
  }
  ```
- **Error Responses**:
  - **403**: Only admin can add devices
  - **404**: Location not found, or device not found (no sensor data received yet)

### PATCH `/api/locations/:id/devices/:deviceId/hide`
Hide a device in a location (Admin only, requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "Device hidden" }
  }
  ```

### PATCH `/api/locations/:id/devices/:deviceId/show`
Show (unhide) a device in a location (Admin only, requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "Device revealed" }
  }
  ```

### DELETE `/api/locations/:id/devices/:deviceId`
Remove a device from a location (Admin only, requires authentication).
- **Headers**:
  ```
  Authorization: Bearer <jwt-token>
  ```
  > **Note**: Admin ID is extracted from JWT token
- **Response (200)**:
  ```json
  {
    "success": true,
    "data": { "message": "Device removed from location" }
  }
  ```
- **Error Responses**:
  - **403**: Only admin can remove devices
  - **404**: Location not found
